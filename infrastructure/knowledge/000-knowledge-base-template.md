## 1. Introduction
This template defines the structure for creating knowledge blocks that agents can ingest to gain context about specific domains or projects.

## 2. Metadata Section
Every knowledge block must start with a YAML frontmatter block.

```yaml
---
title: "Topic Name"
description: "Brief description of the knowledge block"
tags: ["tag1", "tag2"]
last_updated: "YYYY-MM-DD"
audience: "agents/users"
---
```

## 3. Core Content Structure

### 3.1. Executive Summary
A 150-word summary of the topic.

### 3.2. Key Concepts
A table defining the most important terms.

| Term | Definition | Context |
| :--- | :--- | :--- |
| Concept A | Definition of A | Usage in OKS |

### 3.3. Technical Details
Detailed explanation of the topic, including schemas, formulas, or logic.

### 3.4. Related Resources
Links to other documents or external APIs.
