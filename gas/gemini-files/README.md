# Gemini + Google Drive File Processor (Google Apps Script)

Process files in Google Drive using the Gemini API. Supports summarization, analysis, and content extraction.

## Deployment

1. Go to [script.google.com](https://script.google.com) → New project.
2. Copy-paste `Code.gs` into the editor.
3. Enable the Gemini API and set your API key in script properties.
4. Deploy as **Web App**.
