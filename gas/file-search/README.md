# Google Drive File Search MCP Tool (Google Apps Script)

Fast file search over Google Drive, exposed as an MCP-compatible tool.

## Deployment

1. Go to [script.google.com](https://script.google.com) → New project.
2. Copy-paste `Code.gs` into the editor.
3. Deploy as **Web App** (Execute as: Me, Access: Anyone).
4. Copy Web App URL → paste in Open Knowledge Studio MCP panel.
