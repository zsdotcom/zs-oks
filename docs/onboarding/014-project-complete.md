# 014 — Project Complete

Congratulations on completing the onboarding journey! This guide covers how to wrap up a project, archive your work, and plan your next steps.

## Project Completion Checklist

- [ ] **1. Export final deliverables** — Export all documents in final formats (PDF, HTML, Markdown).
  - Go to each document in the Editor
  - Use **Download PDF** or **Download HTML** for final versions
  - Save version snapshots with the version history feature

- [ ] **2. Back up the project** — Go to **Settings → General → Export JSON** to download a complete backup of your entire workspace, including all project files and configurations.

- [ ] **3. Archive the Kanban board** — Review all tasks, move completed ones to "Done", and note any unfinished items for future reference.

- [ ] **4. Review agent performance** — Go to **Dashboard → Agent Metrics** to review:
  - Which agents were most helpful
  - Total tasks completed
  - Time spent per agent
  - Quality and accuracy of outputs

- [ ] **5. Clean up the knowledge base** — Remove temporary or draft files. Organize remaining files into clean folder structures for future reference.

- [ ] **6. Save key learnings** — Create a "Project Retrospective" document with:
  - What went well
  - What could be improved
  - Key findings and insights
  - Recommendations for next time
