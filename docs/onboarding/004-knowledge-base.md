# 004 — Build Your Knowledge Base

The knowledge base stores all your documents, files, and data. It's the core of your workspace.

## Step-by-Step

- [ ] **1. Open the Knowledge Base** — In the workspace sidebar (left), scroll down to **Knowledge Base** section.

- [ ] **2. Browse existing files** — You'll see starter files like:
  - `Coding Standards.md` — Project guidelines
  - `Architecture Map.json` — App architecture
  - `WHO Field Report.md` — Epidemiology report template
  - `Quarterly Projections.csv` — Sample data

- [ ] **3. Create a new folder**:
  - Click **+ Folder** at the top of the knowledge base section
  - Enter a name (e.g., "Research Papers")
  - Press Enter

- [ ] **4. Upload a file**:
  - Click **+ File** or drag-and-drop a file into the knowledge base
  - Supported types: Markdown (.md), Text (.txt), JSON (.json), CSV (.csv), PDF (.pdf), Excel (.xlsx), Images (.png/.jpg)

- [ ] **5. Organize files** — Drag files into folders to keep things organized.

- [ ] **6. Open a file** — Click any file to open it in the **Editor** tab. The view switches automatically.

- [ ] **7. Mark files as active** — Toggle the active state (eye icon) to include/exclude files from AI context.

## File Types

| Type | Icon | Purpose | Preview |
|------|------|---------|---------|
| Markdown | 📝 | Notes, reports, documentation | Live rendered preview |
| CSV | 📊 | Tabular data | Table view |
| JSON | 📋 | Configuration, structured data | Formatted view |
| PDF | 📄 | Imported documents | Embedded PDF viewer |
| Image | 🖼️ | Diagrams, photos, screenshots | Image preview |
| Excel | 📑 | Spreadsheets | Sheet viewer |

## Knowledge Base Tips

- Use folders to create a logical hierarchy
- Mark key reference materials as **Active** so AI can access them
- Use the **Search** tab to find files by name or content
- Keep related files together in the same folder
- Export your entire knowledge base from **Settings → Export All Data**
