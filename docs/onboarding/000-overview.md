## How to Use These Guides

- Each guide has **interactive checkboxes** — tick them off as you complete each step
- **Bold terms** are UI elements you can click
- `Code blocks` are file names, keyboard shortcuts, or commands
- Diagrams show workflows visually
- Links at the bottom connect to related guides and reference docs

## Prerequisites

- A modern browser (Chrome 120+, Firefox 120+, Edge 120+, Safari 17+)
- An internet connection for first load (the app works offline afterward)
- (Optional) An API key for an AI provider
