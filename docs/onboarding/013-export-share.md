# 013 — Export & Share

Export your work in multiple formats, share with collaborators, and back up your data.

## Export Options

### Exporting Documents

| Format | Method | Best For |
|--------|--------|----------|
| **Markdown (.md)** | Editor → Download MD | Editing in other tools |
| **HTML (.html)** | Editor → Download HTML | Web publishing |
| **PDF** | Editor → Print/Download PDF | Reports, formal documents |

### Exporting Data

- [ ] **Export all data** — Go to **Settings → General → Export JSON** to download your complete workspace as a JSON file. This includes:
  - All files and folders
  - Provider configurations
  - A2A agent settings
  - Kanban boards
  - MCP server configurations
  - Skills and connectors
  - Webhooks and saved prompts

- [ ] **Export file list (CSV)** — In **Settings → General → Export CSV** to download a spreadsheet of all file metadata.

- [ ] **Import data** — Use the **Import** button in Settings to restore a previous JSON backup.

### Sharing Documents

- **Print**: Use the Print button in the Editor to print or save as PDF
- **Copy**: Use the Copy button to copy document content to clipboard
- **Email**: Sign in with Google and use the **Gmail Compose** button to send documents as email

## Step-by-Step

- [ ] **1. Export a document** — Open any file in the Editor → click **Download MD** or **Download HTML**.

- [ ] **2. Export as PDF** — Click **Print to PDF** for browser print dialog, or **Download PDF** for a direct file.

- [ ] **3. Export full backup** — Go to **Settings → General → Export JSON** to save your entire workspace.

- [ ] **4. Import a backup** — In **Settings → General → Import**, select a previous JSON backup file to restore.

- [ ] **5. Send via Gmail** — Click the **Mail icon** in the header (requires Google sign-in).

## Cloud Sync

- **Google Workspace**: Sign in with Google to access Drive, Docs, and Sheets
- **GitHub**: Sign in with GitHub to sync with repositories
- **Google Drive**: Store and retrieve files from your Drive

## Backup Tips

- Export your workspace regularly (weekly is recommended)
- Store backups in a safe location (cloud storage, external drive)
- Before major changes, export a backup first
- Backup includes all app configurations — not just documents
