# 009 — Templates

Templates let you quickly create structured documents. The app includes 20 pre-built templates across research, epidemiology, development, and more.

## Available Templates

### Epidemiology & Clinical
- WHO Field Epidemiology Report
- Outbreak Situation Report (SitRep)
- Line Listing Template
- Rapid Risk Assessment
- Contact Tracing Form
- WHO Guidelines Summary
- Community Health Assessment
- Vaccination Campaign Plan
- Case Series Report
- Clinical Trial Protocol

### Research
- Systematic Literature Review (PRISMA)
- Academic Paper (IMRaD)
- Thesis Outline
- Literature Review Matrix
- Epidemiological Data Dictionary

### Code & Development
- Code Review Checklist
- Technical Design Document
- Architecture Decision Record (ADR)
- Test Plan Template
- API Reference Documentation
- Changelog
- Project README

### Diagrams & Math
- Flowchart (Mermaid)
- Sequence Diagram (Mermaid)
- Gantt Chart (Mermaid)
- ER Diagram (Mermaid)
- Statistical Formulas (KaTeX)
- Epidemiological Formulas (KaTeX)

## Step-by-Step

- [ ] **1. Go to Templates** — Click the **Templates** tab in the header to browse all available templates.

- [ ] **2. Browse by category** — Templates are organized by category:
  - **Epidemiology** — Red
  - **Research** — Green
  - **Mermaid** — Blue
  - **Math** — Purple
  - **Custom** — Gray

- [ ] **3. Insert a template** — In the Editor, click the **+ Templates** button and select a template to append it to your document.

- [ ] **4. Fill in the template** — Replace placeholder text (marked with `:`) with your own content.

- [ ] **5. Customize the template** — Add, remove, or reorder sections as needed.

## Creating Your Own Templates

Any document you create can serve as a template. To reuse content:
1. Create your document in the Editor
2. Save a version (for reference)
3. Use the **Copy** button to copy the content
4. Paste into a new file when needed

For a more permanent approach, you can add templates to the app's data files.

## Tips

- Templates include Mermaid diagrams and KaTeX formulas ready to use
- Fill in **all** marked sections for complete documents
- Epidemiological templates include common formulas pre-inserted
- Code templates follow industry best practices
- Use the Literature Review Matrix for comparing multiple sources
