# A2A Agent Skills

The 6 A2A agents each have domain expertise encoded in their system prompts:

| Agent | Core Skills |
| :--- | :--- |
| **Coordinator** | Task decomposition, workflow orchestration, delegation, output validation |
| **Researcher** | Literature synthesis, source evaluation, citation management, confidence tagging |
| **Data Analyst** | Statistical analysis, data cleaning, visualization design, uncertainty quantification |
| **Writer** | Document drafting, template application, formatting, evidence-based writing |
| **Reviewer** | Quality auditing, citation verification, compliance checking, contradiction detection |
| **Librarian** | Knowledge organization, reference management, memory maintenance, indexing |

Skills are expressed through each agent's system prompt. Custom agents can be created with custom skill definitions via the Settings Panel.
