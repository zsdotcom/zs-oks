# 000 — Accessibility Documentation

## Current Accessibility Features

### Color Contrast

All text and background combinations meet **WCAG AA minimum** (4.5:1 contrast ratio). The cyan-research theme defines text colors against dark/light/sepia/forest/ocean/midnight/solarized backgrounds with ratios verified during theme definition. The accent color `#8B5CF6` on standard backgrounds exceeds AA for large text and AA for normal text.

### Focus Indicators

All keyboard-focusable elements display a **2px `#8B5CF6` outline** when focused. The outline uses `outline-style: solid` and is never replaced with `outline: none` without providing an alternative focus style. This applies to:

- Buttons (icon-only and text)
- Input fields and textareas
- Select dropdowns
- Interactive list items
- Tab panels and accordion triggers

### Screen Reader Support

- **Semantic HTML:** All interactive elements use native `<button>`, `<input>`, `<select>`, and `<textarea>` elements rather than generic `<div>` elements with click handlers.
- **aria-labels:** All 36 icon-only buttons in the [`lucide-shim`](../../src/components/icons/lucide-shim.tsx) component have descriptive `aria-label` attributes (e.g., `"Send message"`, `"Toggle sidebar"`, `"Close panel"`).
- **Landmarks:** The app shell uses `<header>`, `<main>`, `<aside>`, and `<footer>` semantic elements.
- **Live regions:** Not yet implemented for dynamic content (see [What's Not Yet Implemented](#whats-not-yet-implemented)).

### Reduced Motion

A `prefers-reduced-motion` media query disables all CSS animations and transitions:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

This is declared in [`src/index.css`](../../src/index.css) and covers all theme transitions, panel animations, and hover effects.

### Font Scaling

All font sizes use **rem units** (not px), respecting the browser's font size setting. The base font size is `16px` (browser default) with scaling:

| Element | Size |
|---------|------|
| Body text | `0.875rem` (14px) |
| Headings | `1rem`–`1.5rem` |
| Code | `0.8125rem` (13px) |
| Small / meta | `0.75rem` (12px) |

No `font-size` is set in px anywhere in the application CSS.

### Keyboard Navigation

All interactive elements are reachable via sequential Tab navigation. The agent panel, chat input, settings forms, Epi Map controls, ICD-11 search, and document editor all respect native tab order. No element has a tabindex > 0. Modals trap focus within the modal container.

## What's Not Yet Implemented

| Feature | Priority | Notes |
|---------|----------|-------|
| **Skip-to-content links** | High | First focusable element should skip navigation to main content area |
| **ARIA live regions** | High | Chat messages, agent status updates, and search results need `aria-live="polite"` announcements |
| **Comprehensive screen reader testing** | Medium | Manual testing with NVDA / VoiceOver / JAWS not yet performed |
| **ARIA expanded/collapsed** | Medium | Collapsible panels and accordions should announce expanded state |
| **Focus management in modals** | Medium | Focus should return to trigger element on modal close (partial implementation) |
| **Error announcements** | Low | Form validation errors should use `aria-describedby` and `role="alert"` |
| **Heading hierarchy audit** | Low | Verify `h1`→`h6` hierarchy is maintained in all views |
| **Touch target sizing** | Low | Verify all interactive targets meet 44x44px minimum |

---

## Future Improvements Roadmap

1. **Skip-to-content link** — Add a visually hidden skip link as the first focusable element in `src/index.tsx`
2. **ARIA live regions** — Wrap dynamic content areas in `aria-live="polite"` containers; use `role="status"` for transient updates
3. **Screen reader audit** — Run automated axe-core checks in CI; manual audit with NVDA
4. **Focus trap refinement** — Ensure modal close returns focus to the triggering element
5. **Touch targets audit** — Use Playwright to verify all buttons are ≥44x44 CSS pixels
6. **Color-blind palettes** — Add a high-contrast theme option for users with color vision deficiency
