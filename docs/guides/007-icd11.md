# 070 — ICD-11 Lookup Guide

---

## 1. What is ICD-11?

The **International Classification of Diseases, 11th Revision (ICD-11)** is the global standard for diagnostic health information developed by the World Health Organization (WHO). It provides a common language for reporting and monitoring diseases, health conditions, and causes of death.

Open Knowledge Studio includes an **offline ICD-11 lookup service** with 50 curated codes covering all major disease categories across chapters 1–23.

Implemented in `src/services/icd11Service.ts` and `src/components/ICD11Lookup.tsx`.

---

## 2. Opening the ICD-11 Panel

1. Click the **Book icon** in the header toolbar
2. The ICD-11 Lookup panel opens as a slide-over panel on the right side
3. Use the search bar or browse codes by chapter

---

## 3. Search Functionality

The search is **debounced** (300ms delay) and matches against:

- **Code** — Exact or partial code match (e.g., `1A00` for Cholera)
- **Title** — Disease name (e.g., "malaria", "diabetes")
- **Chapter** — Disease category (e.g., "Infectious diseases", "Neoplasms")
- **Description** — Full text description

Results display:
- A colored **code badge** (e.g., `1A00`)
- The **title** of the condition
- The **chapter** it belongs to
- The **description** with clinical details

### Example Searches

| Search Query | Results |
|:---|:---|
| `cholera` | 1A00 — Cholera (Infectious diseases) |
| `diabetes` | 5A10 — Type 1 diabetes, 5A11 — Type 2 diabetes |
| `mental` | 6A70 — Depression, 6B00 — Bipolar, mental health chapter entries |
| `1A` | All chapter 1 infectious disease codes |

## 6. FHIR Integration

The ICD-11 service is designed with FHIR (Fast Healthcare Interoperability Resources) compatibility in mind. The `ICD11Entry` interface maps naturally to FHIR `CodeableConcept` structures:

```typescript
interface ICD11Entry {
  code: string;        // ICD-11 code (e.g., "1A00")
  title: string;       // Human-readable title
  chapter: string;     // Disease category
  description: string; // Clinical description
}
```

This enables integration with healthcare systems and standards-based research workflows.

---

## 7. API Reference

```typescript
// Search by query string (matches code, title, chapter, description)
function searchICD11(query: string): ICD11Entry[]

// Look up by exact code
function getICD11ByCode(code: string): ICD11Entry | undefined

// Get all codes
function getAllICD11Codes(): ICD11Entry[]

// Filter by chapter name
function getICD11ByChapter(chapter: string): ICD11Entry[]
```

All searches are case-insensitive.

## 8. Using Codes in Research

ICD-11 codes can be used alongside other tools:

1. **Copy a code** from the lookup panel
2. **Search** for related epidemiological data using the [Public Data APIs](100-public-data.md)
3. **Plot** disease locations on the [EpiMap](060-epi-map.md)
4. **Ask agents** to analyze data using the code

Example: "Find me the ICD-11 code for dengue fever, then search for recent dengue case data from WHO."
