# 093 — PDF Export

---

## 1. Description

The `WorkspaceDocumentEditor` now has two PDF export buttons in the toolbar:
- **Print to PDF** — Opens a new window with a styled HTML document and triggers `window.print()` (the browser's built-in PDF save dialog)
- **Export PDF** — Downloads an HTML file that preserves KaTeX rendering, optimized for print

## 2. Implementation

**File:** `src/components/WorkspaceDocumentEditor.tsx`

### `exportToPDF(fileName, html, isDownload)`

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `fileName` | `string` | Document name used for title and filename |
| `html` | `string` | Pre-rendered markdown HTML (from `parse()`) |
| `isDownload` | `boolean` | `false` = open print dialog; `true` = download as HTML |

### Print styles
- Serif font (Georgia/Times New Roman) for reading comfort
- 12pt base font size with proper heading hierarchy
- Page margins via `@page { margin: 2cm; }`
- `page-break-inside: avoid` on tables, pre blocks, and Mermaid diagrams
- Auto-generated footer: "Generated by Open Knowledge Studio"

### KaTeX support
The export HTML includes both the KaTeX CSS and JS from CDN, with an inline script that auto-renders math elements on page load.
