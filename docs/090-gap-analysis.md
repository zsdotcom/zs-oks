# 090 — Gap Analysis & Enhancement Report

**Document Version:** 1.0
**Date:** July 25, 2026
**Author:** Manus AI
**Target Repository:** Open Knowledge Studio v1.0

---

## 1. Overview

This document presents a comprehensive gap analysis of the Open Knowledge Studio repository against current best practices for browser-native, multi-agent knowledge management systems. It identifies critical issues, proposes major enhancements (all free/no-dependency), and outlines the required tech stack upgrades.

---

## 2. Critical Issues Identified

### 2.1 Deprecated API Models
The repository previously referenced `gemini-2.0-flash` and `gemini-2.0-flash-lite`. These models have been shut down or deprecated by Google AI.
- **Action Required:** Migrate all API calls to `gemini-2.5-flash` or `gemini-2.5-pro` immediately to ensure the Coordinator and Writer agents function correctly.

### 2.2 localStorage Storage Limit
The previous implementation relied on `localStorage`, which is capped at 5-10 MB per domain. This is insufficient for a robust knowledge base containing documents, vector embeddings, and agent histories.
- **Action Required:** Migrate entirely to **IndexedDB**, which supports gigabyte-scale storage per origin [1].

### 2.3 Missing Full-Text & Semantic Search
There was no client-side search engine implemented, forcing users to rely on browser-level `Ctrl+F`.
- **Action Required:** Implement **Orama JS**, an 80KB client-side search library that provides 5-10ms full-text and vector queries without any backend [2].

### 2.4 Lack of PWA/Offline Support
The application lacked Service Workers, meaning it could not function when the user's internet connection dropped.
- **Action Required:** Implement a Service Worker (`public/sw.js`) to cache the application shell and API responses for true offline-first capability.

### 2.5 No Version Control
The document editor had no mechanism for revision history or rollback.
- **Action Required:** Implement an auto-save protocol and manual snapshot feature within the Working Memory tier.

## 3. Major Enhancement Opportunities (Zero Cost)

### 3.1 Voice-to-Text Dictation
Utilize the native **Web Speech API** built into modern browsers to allow users to dictate inputs to the Coordinator agent without needing a paid transcription service.

### 3.2 Drag-and-Drop File Uploads
Leverage the **File System Access API** to allow users to drag and drop large datasets directly into the Data Analyst's workspace without uploading them to a server.

### 3.3 Epidemiological Mapping
Integrate **Leaflet.js** (a lightweight, open-source mapping library) to visualize geographic data generated by the Data Analyst agent.

### 3.4 EpiCurve Generators
Utilize existing Canvas charting libraries (or build custom SVG renderers) to generate epidemic curves directly from the case data processed by the Researcher agent.

### 3.5 WHO/ICD-11 Code Lookups
Create a built-in snippet tool within the Writer agent to quickly insert standardized medical codes (ICD-11) into reports.

### 3.6 Client-Side PDF Export
Implement PDF generation using lightweight client-side libraries like `jspdf` and `html2canvas` to allow the Writer agent to export final documents without a backend rendering service.

## 4. Tech Stack Upgrade Required

To support the v1.0 architecture, the following major upgrades to the tech stack are required:

| Dependency | Previous Version | Required Version | Justification |
| :--- | :--- | :--- | :--- |
| **Vite** | 6.2.x | **8.1.x** | Switches to the Rust-based Rolldown bundler for massive build speedups. |
| **React** | 19.1.x | **19.2.x** | Latest stable release with improved concurrent features. |
| **TypeScript** | 5.8.x | **6.0.x** | Required for compatibility with React 19.2 and latest DOM typings. |
| **Plugin React** | 5.0.x | **6.0.x** | Mandatory update for Vite 8 compatibility. |
| **@types/node** | 22.x | **26.x** | Updated type definitions for Node.js APIs. |
| **KaTeX** | N/A | **0.17.0+** | Pinned version for fast client-side math rendering. |
| **Mermaid** | N/A | **11.16.0+** | Pinned version for color-coded real-time diagram rendering. |

## 5. Implementation Roadmap

1. **Phase 1: Core Infrastructure Upgrade**
   - Upgrade Vite, React, and TypeScript versions.
   - Migrate all state from `localStorage` to IndexedDB (`db/indexedDB.ts`).
   - Implement the Service Worker for PWA support.

2. **Phase 2: Multi-Agent & Memory Integration**
   - Implement the 6-tier memory schema as defined in `docs/070-memory-architecture.md`.
   - Integrate Transformers.js for embedding generation in Web Workers.
   - Implement the A2A protocol using `BroadcastChannel`.

3. **Phase 3: UI/UX & Feature Enhancements**
   - Implement the color-coded agent tracking in the Chat Interface.
   - Add Mermaid.js live preview for the Writer and Data Analyst agents.
   - Integrate Orama JS for semantic search in the Knowledge Base Manager.
